# 欢迎使用 Plume

这是一篇笔记。按 **⌃⌥Space** 把 Plume 收起，再按一次，它就会回来。

## 先记住三个键

- **⌘N** 新建笔记
- **⌘P** 查找笔记
- **⌘K** 其他所有操作

Plume 默认保持固定大小。如果想让它随笔记内容增长，按 **⇧⌘/**。

## 直接写

Markdown 会在你输入时即时排版。

试试 **粗体**、*斜体*、`代码`、标题、列表或复选框。

- [ ] 勾选这个框
- [x] 这个已经完成了

你正在编辑的那一行会保留 Markdown 原文，所以你始终能看到自己写的是什么。

> 每篇笔记都是你自己文件夹里的一个普通 `.md` 文件。没有数据库，没有账号，也不用登录。

随时可以用 **⌘K → 在访达中显示** 找到它们。

这些就足够上手了。

欢迎删除这篇笔记，Plume 不会再把它放回来。
